# 专属助手最小定时任务

只建议先落这 4 个任务：

1. `heartbeat`
   - 周期：每 30 分钟
   - 作用：整理短期记忆，补齐未归档事项
2. `daily-summary`
   - 周期：每天 21:30
   - 作用：汇总当天任务、决策、阻塞
3. `workspace-backup`
   - 周期：每天 03:30
   - 作用：备份专属工作区和 agent 配置
4. `model-health`
   - 周期：每 6 小时
   - 作用：检查默认模型和备用模型可用性

不建议第一阶段启用：

- 自动安装技能
- 自动自我进化
- 自动外发通知
- 扫描全量群聊并主动回复
